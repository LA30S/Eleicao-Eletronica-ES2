Sistema de Simualação de Votação Eletrônica

Utilizando: Node JS 24 alpine com Docker compose
API: Expressjs
Database: MongoDB utilizando mongoose
Frontend: Ionic usando angular

Para instalar as dependências: npm install
Caso dê ruim: Tente instalar o npm install de cada parte(tipo primeiro front depois back)

Este readme pode ser utilizado para detalhar partes do projeto e pode também ser utilizado como uma checklist de implmentações

Para montar a imagem: docker compose build
Para subir no docker(rodar): docker compose up
Para descer o docker(parar): docker compose down
Compilar e rodar: docker compose up -d --build

Se der ruim com alguma imagem, troca a versão e da **docker compose build --no-cache** para atualizar
